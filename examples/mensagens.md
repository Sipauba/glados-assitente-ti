# Exemplos de mensagens

Exemplos sintéticos que ilustram categorias do workflow; não representam conversas nem dados reais.

- “Pode verificar o carregamento 12345?” — carregamento.
- “Como executo a rotina de fechamento no WinThor?” — rotina.
- “Preciso derrubar a sessão do usuário de teste.” — sessão.
- “Abra um chamado para o erro de impressão no computador de teste.” — abertura de chamado.
- “Adicione esta informação ao chamado 12345.” — resposta a chamado.
- “Qual é o telefone do usuário de teste?” — localização de usuário.
- “Qual o status do pedido 12345?” — consulta de pedido e possível confirmação.
- “Há estoque do produto 12345 na filial 1?” — consulta de estoque.
